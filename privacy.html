Privacy Policy

Last updated: August 15, 2026

"shorts-automation" is a personal, single-user automation tool built and operated by its developer for their own use only. It has no other users.

What data is accessed

Through TikTok Login Kit / Content Posting API OAuth, the tool accesses only the developer's own TikTok account, for the sole purpose of uploading video drafts to that same account. No data from any other TikTok user is accessed.

How data is used and stored

Access tokens are stored locally on the developer's own computer and are never transmitted to any third party or server other than TikTok's official API endpoints. No user data is sold, shared, or used for advertising or analytics.

Data retention and deletion

Locally stored tokens can be deleted at any time by removing them from the developer's device. The developer may also revoke access at any time from TikTok's account settings.
